# WebUI 管理界面

Device Faker 提供现代化的 Web 管理界面，可以直接在 WeaveMask / KernelSU / APatch 等root管理器的模块页面中打开，不必手改 TOML。

## 打开方式

安装模块后，在模块管理器中找到 **Device Faker**，点击「WebUI」或「设置」入口即可打开。

::: info 兼容说明
WebUI 采用纯 KernelSU WebUI API 实现，支持 KernelSU、WeaveMask 和 APatch 等兼容 API 的root管理器的模块 WebUI 入口。
:::

## 页面总览

| 页面 | 主要功能 |
|------|---------|
| **状态 (Status)** | 模块信息、配置摘要、模块动态 |
| **模板 (Templates)** | 创建/编辑/删除机型模板、批量应用到包名、导入导出、重命名 |
| **应用 (Apps)** | 查看已安装应用、筛选系统应用、查看配置状态、编辑应用配置 |
| **设置 (Settings)** | 界面设置、工具调用、模块设置 |

## 应用管理

### 应用列表与筛选

- 列出设备上已安装的应用，并显示其当前是否已配置伪装
- 支持开关「显示系统应用」，方便给系统应用也配置伪装
- 支持按包名/应用名搜索

### 多用户应用显示

同一应用的多用户实例（例如 `com.foo` 和 `com.foo@999`）会**按包名分组排列**，方便你为不同用户分别配置。

### 编辑应用配置

点击某个应用进入配置编辑：

- 直接填写各字段（制造商、品牌、型号、设备代号等）
- 选择已存在的[机型模板](./configuration/index.md#方式一机型模板)快速套用
- 设置 `companion_resetprop`、`force_denylist_unmount`、`dpi` 等开关
- 在 `custom_props` 区域添加自定义属性

### 给应用套用模板

在应用编辑页选择「应用模板」，即可把某个模板的所有字段一次性填充进来，再按需微调。

## 模板管理

### 创建与编辑模板

- 填写机型字段，保存为命名模板
- 模板创建后可在多个应用间复用

### 批量应用到包名

编辑模板时，在 `packages` 列表中添加包名。保存后，这些包名会自动使用该模板。

### 导入 / 导出

- 支持把当前所有模板导出为文件备份
- 支持导入备份文件恢复模板

### 在线模板库

WebUI 内置在线模板源，可以从社区模板仓库一键导入：

- 仓库地址：[device_faker_config](https://github.com/Seyud/device_faker_config)
- 支持按品牌、型号分类浏览
- 支持搜索

::: tip 欢迎贡献
如果你有整理好的机型配置，可以提交到 `device_faker_config`，帮助更多用户。
:::

### 重命名已存在模板

模板支持重命名，重命名后所有引用该模板的应用配置会自动更新。

## 手势与导航

- **侧滑返回逐级导航**：在多层页面（应用 → 编辑 → 字段详情）之间侧滑可返回上一级
- **左右滑动切换页面**：在底部 Tab 之间可以通过滑动快速切换

## 多语言

WebUI 界面支持多语言切换，目前支持：

- 简体中文
- English
- Türkçe

语言设置与系统语言默认保持一致，也可在 WebUI 设置页手动切换。
